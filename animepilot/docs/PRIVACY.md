# Vie privée

- **Aucun compte, aucun serveur AnimePilot, aucune statistique d'usage, aucune publicité.**
- Ta bibliothèque, ta progression, tes notes, ton historique et tes réglages sont stockés **uniquement sur ton téléphone** (IndexedDB du navigateur).
- **Données envoyées à AniList** :
  - le texte de tes recherches ;
  - les identifiants des titres dont l'app demande les infos (fiche, calendrier, mise à jour).
  
  AniList voit donc ton adresse IP, comme pour tout site web. Aucune donnée personnelle (notes, progression) ne lui est envoyée.
- **Affiches** : chargées depuis le CDN d'AniList (`s4.anilist.co`, sans référent), puis mises en cache sur le téléphone (400 max).
- **Sauvegardes** : le fichier JSON exporté contient toute ta bibliothèque. Range-le où tu veux (Fichiers, iCloud Drive) ; l'app ne l'envoie nulle part.
- **Effacer** : Profil → Données → Tout effacer. Supprimer l'app de l'écran d'accueil efface aussi ses données.
- **iPhone** : Safari peut effacer les données d'un site non installé après 7 jours sans visite. **Installe l'app sur l'écran d'accueil** et exporte une sauvegarde de temps en temps.
