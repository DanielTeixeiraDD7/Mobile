# Coûts

**Total : 0 €.** Aucun abonnement, aucune carte bancaire, aucune clé d'API payante.

| Poste | Solution | Coût |
|---|---|---|
| Hébergement | GitHub Pages (dépôt existant) | 0 € |
| Catalogue | API publique AniList, sans clé | 0 € (usage non commercial) |
| Base de données | IndexedDB sur le téléphone | 0 € |
| Rappels | notifications locales (app ouverte) + export calendrier `.ics` | 0 € |
| Assistant | règles locales en TypeScript (pas d'IA en ligne) | 0 € |
| Recommandations | calcul local | 0 € |
| Build / tests | outils open source (Vite, Vitest, Playwright) | 0 € |

## Ce qui n'est volontairement pas utilisé

- Pas de serveur de notifications push (nécessiterait un service tiers à configurer).
- Pas d'API d'IA (OpenAI, Anthropic…) : payantes.
- Pas d'Apple Developer Program (99 €/an) : nécessaire seulement pour une app native sur l'App Store / TestFlight.

Si une fonctionnalité future demande un service payant, elle sera signalée ici **avant** d'être ajoutée, jamais activée en silence.
