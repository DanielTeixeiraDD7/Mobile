Text diff checker

Paste two versions of a text, config file or snippet and see which lines were added or removed.

Runs locally: your input never leaves this page.

~/bitbench/text-diff local

How it works

The comparison is line by line, using the Myers diff algorithm (the same family as git diff) from the open-source jsdiff library. Removed lines are marked “−” with the original line number, added lines “+” with the new line number.

Options

  • Ignore whitespace: leading and trailing spaces are ignored and runs of spaces or tabs count as one. Useful for re-indented code.
  • Ignore case: “Hello” and “hello” are treated as equal.
  • Show changes only: hides unchanged lines in long texts.

Windows (CRLF) and Unix (LF) line endings are treated the same, and a missing final newline does not count as a change.

Unified diff

“Copy patch” and “Download .diff” produce a standard unified diff with 3 lines of context, which tools such as git apply or patch can read. The patch is computed on the raw texts, without the ignore options.

Limits

  • Changes are shown per line, not per word inside a line.
  • Very large texts (tens of thousands of lines with many changes) can take a few seconds.
