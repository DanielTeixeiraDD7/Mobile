JSON formatter and validator

Pretty-print or minify JSON, sort keys, and find exactly where invalid JSON breaks.

Runs locally: your input never leaves this page.

~/bitbench/json-formatter local

How to use it

  1. Paste JSON on the left (or load the example).
  2. Choose Format or Minify, the indentation and whether to sort keys alphabetically.
  3. Copy or download the result. If the input is invalid, the error gives the line, the column and the reason.

Error messages that say what is wrong

Browsers report JSON errors differently, and some do not give a position. This tool runs its own small validator (following RFC 8259) to point to the first error and explain it: trailing commas, single quotes, unquoted keys, raw line breaks inside strings, leading zeros, or content after the end of the value.

Example

{"name": "Ada", "tags": ["math",],}

Result: “Line 1, column 33: Trailing comma before “]” is not allowed in JSON.”

Limits

  • Strict JSON only: comments, trailing commas and single quotes (JSON5, JSONC) are reported as errors.
  • Numbers are read as JavaScript numbers: integers larger than 2^53 (9,007,199,254,740,992) lose precision when reformatted.
  • Duplicate keys are allowed by JSON.parse: the last value wins.
  • Large documents (several MB) work but may take a moment; everything stays in this tab.
