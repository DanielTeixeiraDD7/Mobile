About Bitbench

Bitbench is a small collection of developer utilities built around one rule: what you paste stays in your browser.

How the tools are built

  • Every tool runs client-side. The site is a set of static files; there is no API that receives your input.
  • Each tool is covered by automated tests with known reference values (for example the official SHA-256 test vectors, RFC 9562 UUID layout, RFC 4180 CSV quoting).
  • Two open-source libraries are used: sql-formatter (MIT) for SQL and jsdiff (BSD-3-Clause) for diffs. Everything else is written for this site.

Limits

The tools are provided as they are, without warranty. Check results before relying on them in production; each page lists what is and is not supported.

Found a bug? Let us know, ideally with the input that triggers it.
