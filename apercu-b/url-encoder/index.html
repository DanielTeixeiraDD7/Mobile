URL encode and decode

Percent-encode text for use in a URL, or decode an encoded URL back to readable text.

Runs locally: your input never leaves this page.

A value or a complete URL?

  • A value (a query parameter, a path segment) must have every special character encoded, including / ? & = #, otherwise it would change the structure of the URL. This uses encodeURIComponent: a&b=c → a%26b%3Dc.
  • A complete URL must keep its structure, so : / ? & = # are left as they are and only spaces and non-ASCII characters are encoded. This uses encodeURI.

Encoding a value as a full URL (or the reverse) is a common source of broken links and injection bugs.

Spaces: %20 or +

In URLs, a space is %20. HTML forms (application/x-www-form-urlencoded) write it as +: tick “Treat + as a space” when decoding form data.

Errors

A lone % or an incomplete UTF-8 sequence (such as %C3 on its own) cannot be decoded: the tool reports it instead of returning a partial result.
