UUID generator

Generate random (v4) or time-ordered (v7) UUIDs, up to 1,000 at a time, and check an existing UUID.

Runs locally: your input never leaves this page.

v4 or v7?

  • v4: 122 random bits. The usual choice for identifiers that must not reveal anything.
  • v7: the first 48 bits are the creation time in milliseconds, followed by random bits (RFC 9562, 2024). v7 UUIDs sort by creation time, which keeps database indexes compact. The creation time can be read from the UUID: use v4 if that matters.

Randomness

Random bits come from crypto.getRandomValues, the browser’s cryptographically secure generator. The version and variant bits are set as required by the standard, so every UUID has the form xxxxxxxx-xxxx-Mxxx-Nxxx-xxxxxxxxxxxx with M = 4 or 7 and N = 8, 9, a or b.

Uniqueness

With 122 random bits, collisions are astronomically unlikely, but not mathematically impossible. Databases should still enforce a unique constraint.
