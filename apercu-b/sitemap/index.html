Tools

  • JSON formatter & validator — Format, minify and validate JSON with exact error positions.
  • JSON to CSV — Convert an array of objects to CSV, nested keys flattened.
  • Text diff — Compare two texts line by line, ignoring case or whitespace.
  • SQL formatter — Readable SQL for 10 dialects, keywords upper or lower case.
  • Base64 encode & decode — UTF-8 safe Base64 and Base64URL, with clear errors.
  • URL encode & decode — Percent-encode a query value or a full URL, and decode it.
  • HTML entities — Escape text for HTML and decode named or numeric entities.
  • JWT decoder — Read a JWT header and payload locally, with expiry dates.
  • Hash generator — SHA-1, SHA-256, SHA-384 and SHA-512 with Web Crypto.
  • UUID generator — Random v4 or time-ordered v7 UUIDs, up to 1,000 at once.
  • Unix timestamp converter — Seconds or milliseconds to dates in UTC and local time.
  • Cron expression helper — Explain a 5-field cron expression and list its next runs.
  • Regex tester — Test JavaScript regular expressions with groups and flags.
  • Colour converter — HEX, RGB and HSL conversions with WCAG contrast ratios.
