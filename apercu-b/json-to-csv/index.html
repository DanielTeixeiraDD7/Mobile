JSON to CSV converter

Turn an array of JSON objects into a CSV file you can open in a spreadsheet, without losing data.

Runs locally: your input never leaves this page.

~/bitbench/json-to-csv local

Conversion rules

  • The input must be an array of objects. A single object becomes one row; an array of plain values becomes a single column named “value”.
  • Nested objects are flattened with dots: {"address": {"city": "Paris"}} becomes a column address.city.
  • Arrays inside an object are written as JSON text in one cell, so nothing is silently dropped.
  • Columns are the union of every key, in order of first appearance. Missing values are empty cells, and the tool tells you how many rows were incomplete.
  • Cells containing the separator, a double quote or a line break are quoted, and quotes are doubled (RFC 4180).

Example

[{"id": 1, "user": {"name": "Ada"}}, {"id": 2, "tags": ["x"]}]
id,user.name,tags
1,Ada,
2,,"[""x""]"

Opening the file in Excel

In locales that use a comma as the decimal separator (France, Germany, Portugal…), Excel expects semicolons: choose the semicolon separator before downloading.

Limits

  • Mixing objects and plain values in the same array is refused, with the index of the first problem item.
  • Values that start with = + − or @ are kept as they are; spreadsheets may interpret them as formulas.
