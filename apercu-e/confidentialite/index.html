Politique de confidentialité

Dernière mise à jour : 19 octobre 2026.

Ce que nous ne collectons pas

  • Pas de compte, pas de formulaire d’inscription.
  • Les valeurs saisies dans les calculateurs ne sont envoyées à aucun serveur : les calculs se font dans votre navigateur.
  • Pas de cookie publicitaire ni de traceur de mesure d’audience sur cette version du site.
  • Les polices de caractères sont hébergées avec le site : aucune requête n’est faite à un service de polices tiers.

Ce qui est stocké sur votre appareil

Pour ne pas perdre votre saisie si vous rechargez la page, les valeurs des calculateurs sont gardées dans le stockage de session de votre navigateur. Elles restent sur votre appareil et sont effacées à la fermeture de l’onglet. Le bouton « Effacer » de chaque calculateur les supprime immédiatement.

Hébergement

Le site est hébergé par Cloudflare (service Cloudflare Pages). Comme tout hébergeur, Cloudflare traite des données techniques de connexion (adresse IP, navigateur, page demandée) pour délivrer les pages et protéger le service contre les abus. Ces traitements relèvent de Cloudflare ; consultez sa politique de confidentialité sur cloudflare.com.

Évolutions

Si nous ajoutons un jour une mesure d’audience, de la publicité ou des liens d’affiliation, cette page sera mise à jour avant, et votre consentement sera demandé lorsque la loi l’exige.

Contact

Pour toute question sur vos données, utilisez la page Contact.
